# ネタメモ

テキストで書けるシンプルなメモアプリ（PWA）。メモごとに「台本モード」に切り替えて、漫才台本のように話者つきで書くこともできます。

## GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作る（例: `netamemo`、Public）
2. このフォルダの中身（`index.html` `manifest.json` `sw.js` `icon-*.png`）をリポジトリ直下にアップロード
3. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/netamemo/` で開ける

更新したときは `sw.js` の `CACHE` の番号（`netamemo-v1` → `v2`…）を上げると、確実に新しい版に切り替わります。

## iPhoneでの使い方

- Safariで開き、共有 →「ホーム画面に追加」して、ホーム画面のアイコンから使ってください（オフラインでも動作）
- メモ画面では左端から右にスワイプすると一覧に戻れます
- 新しいバージョンを公開すると、アプリに「更新」ボタンが出ます
- 右下のボタンで新規メモ。1行目がタイトルになります。入力内容は自動保存されます
- 何も書かずに戻ったメモは自動で消えます
- 一覧で長押しすると、ピン留め・複製・削除
- 削除したメモは ⋯ →「最近削除した項目」から30日間は戻せます
- 上の検索欄で全文検索できます

### 台本モード

- メモ画面右上の「メモ / 台本」で切り替え
- 中身は `名前：セリフ` という普通のテキストのまま保存されるので、メモモードに戻せばそのまま編集できます
- 改行キーで次の行へ（話者は自動で交代）、行頭で削除キーを押すと前の行と結合
- 上の話者ボタンをタップすると、今編集中の行の話者を切り替え
- 行頭の名前をタップすると、話者変更・行の挿入/移動/削除
- 「✎ 話者」で名前の変更・追加・色変更・削除

### iPhoneの「メモ」アプリとの連携

データはすべてプレーンテキストなので、「メモ」アプリとコピーや共有でやり取りできます。

| やりたいこと | 操作 |
| --- | --- |
| ネタメモ → メモ | 共有ボタン → 「メモ」を選ぶ（新規メモにするか、既存のメモに追記するかを選べます） |
| メモ → ネタメモ（新規） | 「メモ」で全文コピー → ネタメモの ⋯ →「クリップボードから新規メモ」 |
| メモ → ネタメモ（上書き） | 「メモ」で全文コピー → 対象メモの ⋯ →「クリップボードの内容で置き換え」 |
| まとめて保存 | ⋯ →「すべて .txt で書き出し」→「ファイルに保存」でiCloud Driveなどへ |
| まとめて読み込み | ⋯ →「ファイルを読み込む」で `.txt`（複数可）や `.json` バックアップ |

※ Webアプリから「メモ」アプリのデータを直接読み書きする手段はiPhoneに用意されていないため、自動で双方向に同期することはできません。

### データについて

- 以前の「漫才台本エディタ」で書いた台本は、最初に開いたときに自動で台本モードのメモとして移行されます
- データはiPhone内（ホーム画面アプリ側）に保存されます。Safariで開いたときのデータとは別になるので、ホーム画面のアイコンから使ってください
- 機種変更やアプリの削除に備えて、ときどき ⋯ →「バックアップを書き出し（.json）」で保存してください
