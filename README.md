# ネタメモ

iPhoneのホーム画面に追加して使う、テキストベースのメモアプリ（PWA）です。
メモごとに「台本モード」に切り替えて、漫才の台本を話者つきで書くこともできます。

**アプリ：https://reipon29.github.io/netamemo/**

## はじめかた

1. iPhoneのSafariで上のURLを開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面の「ネタメモ」アイコンから起動する

※ Safariで開いたときとホーム画面のアプリでは、データの保存場所が別々です。いつもホーム画面のアイコンから使ってください。
※ 一度開けば、オフラインでも使えます。

## 使い方

### メモ

- 右下のボタンで新規メモ。1行目がタイトルになります
- 入力内容は自動で保存されます。何も書かずに戻ったメモは自動で消えます
- 左端から右にスワイプすると一覧に戻ります
- 一覧でメモを左にスワイプすると共有・削除、右にスワイプするとピン留めのボタンが出ます
- 一覧で長押しすると、ピン留め・複製・削除ができます
- 上の検索欄で、メモの全文を検索できます
- 削除したメモは、⋯ →「最近削除した項目」から30日間は戻せます

### 台本モード

- メモ画面の右上の「メモ / 台本」で切り替えます
- 改行キーで次の行へ（話者は自動で交代）、行頭で削除キーを押すと前の行と結合します
- 上の話者ボタンで、編集中の行の話者を切り替えます
- 行頭の名前をタップすると、話者の変更や、行の挿入・移動・削除ができます
- 「✎ 話者」で、話者の名前・色の変更や追加・削除ができます
- 中身は `名前：セリフ` 形式のテキストのまま保存されるので、メモモードに戻してもそのまま読めます
- `A ああああ` のように名前とセリフを半角スペースで区切ったメモも、「台本」に切り替えると台本として読み込めます（2回以上出てくる名前を話者とみなします）

### iPhoneの「メモ」アプリとのやり取り

| やりたいこと | 操作 |
| --- | --- |
| ネタメモ → メモ | 共有ボタン →「メモ」（新規メモにするか、既存のメモに追記するかを選べます） |
| メモ → ネタメモ（新規） | 「メモ」で全文をコピー → ⋯ →「クリップボードから新規メモ」 |
| メモ → ネタメモ（上書き） | 「メモ」で全文をコピー → メモ画面の ⋯ →「クリップボードの内容で置き換え」 |

※ iPhoneの仕組み上、「メモ」アプリと自動で同期することはできません。

### バックアップ

- ⋯ →「バックアップを書き出し（.json）」→「ファイルに保存」で、iCloud Driveなどに保存できます
- ⋯ →「すべて .txt で書き出し」で、メモを1件ずつテキストファイルとして保存できます
- ⋯ →「ファイルを読み込む」で、`.json` のバックアップや `.txt` ファイル（複数可）を読み込めます

機種変更に備えて、ときどきバックアップしてください。

## アップデートのしかた（開発メモ）

1. ファイルを修正したら、`sw.js` の `CACHE` の番号を上げる（例：`netamemo-v1` → `netamemo-v2`）
2. GitHubにアップロード（コミット）する
3. 1〜2分で公開され、アプリを開くと「更新」ボタンが出る

公開の設定：Settings → Pages → Source「Deploy from a branch」、Branch「main」/「/ (root)」
